rn-16kb-check

A CLI that checks React Native Android builds (AAB, APK, AAR) for Google Play's 16 KB page size requirement — and names the npm package behind every native library that fails, with how to fix it. Built after a client's app was rejected by Google Play for exactly this.

Node.jsELF parsingZIP / AABCLICI on macOS · Linux · Windows
npm ↗ GitHub ↗
$ npx rn-16kb-check app-release.aab
✖ FAIL  libcamerafilters.so [arm64-v8a] 4 KB
        from: react-native-legacy-camera@2.1.0
        fix:  upgrade the package

✖ 2 of 4 64-bit libraries are not 16 KB compatible.

use-timezone-overlap

A React / React Native hook that shows your working hours in the visitor's time zone — online now, today's window in their local time and how many hours your days overlap. Handles DST, half-hour offsets and overnight shifts.

ReactReact NativeHookIntl
